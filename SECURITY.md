# Security

Please report security problems privately, not in a public issue. Use **Report a vulnerability** on this repository's **Security** tab, with the steps to reproduce it. You'll get a reply within a few days.

In scope: the code in this repository and [www.aimdropin.com](https://www.aimdropin.com). The live dashboard demos run third-party code inside a sandbox (a CSP `sandbox` with an opaque origin, served from `/demos/`), so a way out of that sandbox counts too.
